# Quickstart: 屏幕录制器 (Screen Recorder)

**Feature**: 001-screen-recorder | **Date**: 2026-10-18

本指南用于开发运行与端到端人工验收。所有场景与 `spec.md` 的 SC/FR 条目对应。

## 1. 环境要求

- Windows 10 1809 及以上 或 Windows 11,x64
- Node.js 24.x(≥ 22.12.0),npm 10+
- 可选:pnpm 10.x
- 磁盘剩余空间 ≥ 2 GB(录制测试用)

## 2. 安装依赖

```powershell
npm install
```

预期:安装成功;`electron` 版本为 44.9.x;无原生模块编译(纯 JS/TS 依赖)。

## 3. 开发运行

```powershell
npm run dev
```

预期:
- 应用启动后**没有前台窗口**,任务栏无图标,系统托盘出现应用图标(FR-002);
- 右击托盘图标出现菜单:录屏 / 设置 / 退出(FR-003)。

## 4. 单元测试

```powershell
npm test          # vitest run
npm run test:watch
```

覆盖范围见 `research.md` §12:settings schema、区域 DPI 换算、文件名、mime 探测、ftyp 检查、窗口过滤、会话状态机。

## 5. 构建安装包

```powershell
npm run build     # electron-vite build + electron-builder --win
```

预期产物(位于 `dist/`):
- `DSH 屏幕录制器 Setup <version>.exe`(NSIS)
- `DSH 屏幕录制器 <version>.exe`(portable)
- 均为 x64,可安装/直接运行于 Windows 10/11。

## 6. 端到端验收场景

按顺序执行,每条均对应 spec 需求/成功标准。

### 场景 A — 托盘 + 全屏录制(SC-001、SC-002、SC-003、FR-003/004/005/009/010)

1. 启动应用;右击托盘 →「录屏」;模式窗口出现,默认选中「全屏」。
2. 点击「开始」;模式窗口关闭,托盘菜单变为「停止录制」。
3. 在桌面进行可见操作约 10 秒(打开记事本输入文字)。
4. 右击托盘 →「停止录制」。
5. 预期:默认存储目录出现 `ScreenRecording_YYYYMMDD_HHmmss.mp4`;用系统播放器打开,内容与操作一致;**无音轨**;从点击「开始」到实际开始 ≤ 10 秒。

### 场景 B — 区域录制(SC-004、FR-006/007)

1. 托盘 →「录屏」→ 选「选定区域」→ 点击「框选」,在屏幕上拖出约 640×480 的区域。
2. 点击「开始」,操作 10 秒,再停止。
3. 预期:输出 MP4 分辨率 = 所选区域尺寸(640×480,按 DPI 换算为物理像素);画面仅包含所选区域。

### 场景 C — 窗口录制(SC-003、FR-008)

1. 打开记事本窗口(非全屏)。
2. 托盘 →「录屏」→「指定应用窗口」→ 列表中选择记事本。
3. 开始录制,在记事本中输入文字,移动窗口位置。
4. 调整记事本窗口大小(放大/缩小),预期:录制继续,输出分辨率保持开始录制时的窗口尺寸(画面按比例缩放)。
5. 最小化或遮挡记事本窗口,预期:录制不崩溃,画面反映窗口真实状态。
6. 停止录制,预期:视频只包含记事本窗口内容,不含桌面其他部分。

### 场景 D — 设置持久化(SC-005、FR-015/016/017)

1. 托盘 →「设置」;把存储位置改为 `D:\recordings`,区域范围改为 `{x:100,y:100,width:800,height:600}`,保存。
2. 退出并重新启动应用(托盘 → 退出;`npm run dev` 再启动)。
3. 打开设置,预期两处值保持;场景 B 录制输出到 `D:\recordings`。

### 场景 E — 窗口关闭自动结束(U4 场景 3)

1. 对记事本开始窗口录制。
2. 关闭记事本窗口。
3. 预期:录制自动结束并保存已录内容;出现成功或结束提示;文件可播放。

### 场景 F — 错误路径(FR-012、Edge Cases)

1. 把存储目录设置为一个只读目录(或删除后无权限重建)。
2. 开始录制,预期:启动前明确报错(`STORAGE_ERROR`),不产生损坏文件。
3. 在设置中输入非法区域(宽 15 DIP,低于 16×16 下限,或超出屏幕),预期:保存被拒绝并显示字段错误。

### 场景 G — 崩溃恢复(章程 Edge Cases)

1. 开始一次录制,等待 5 秒。
2. 用任务管理器结束应用进程。
3. 重新启动应用,预期:系统通知「上次录制可能未完成」;`recording-session.json` 标记已清理;未完成文件保留在输出目录。

### 场景 H — 界面与用户体验(SC-009、FR-022/023/024)

1. 依次打开托盘菜单、模式选择窗口、设置窗口与区域框选覆盖层。
2. 预期:四处界面视觉风格统一(颜色、字体、间距、圆角一致),元素对齐、留白合理,无系统默认控件与自定义样式混杂。
3. 检查按钮、单选、输入框、列表项的默认/悬停/按下/禁用/聚焦状态是否清晰;「开始」按钮为明显的主操作。
4. 分别在 100%、125%、150%、200% 显示缩放下检查:文字清晰、布局不错位、窗口缩放时布局自适应。
5. 邀请 5 名首次使用的用户对界面外观与易用性评分(1–5 分),至少 4 名评分 ≥ 4/5。

### 场景 I — 可用性与性能评分(SC-006、SC-008)

1. 邀请 5 名首次使用的用户,在无指导下完成一次托盘发起的全屏录制。
2. 预期:至少 4 名成功完成任务(SC-006,记录成功人数)。
3. 每名用户对「录制期间目标应用操作是否流畅」按 1–5 分评分(SC-008)。
4. 预期:中位数 ≥ 4/5(记录逐人分数)。

### 场景 J — 截屏与标注

1. 托盘右键 →「截屏」,或按设置中的快捷键(默认 `Ctrl+Shift+S`),然后在屏幕上拖动框选要截取的区域。
2. 在编辑窗口底部工具栏选择「箭头」,在图片上拖动绘制;选择「文本」,点击图片输入文字。
3. 点击「保存图片」,检查存储目录生成 `Screenshot_*.png`;点击「复制图片」,粘贴到画图或聊天工具。
4. 打开设置,在「截屏快捷键」输入框按下新组合键并保存,确认新快捷键立即生效。

预期:截图窗口展示所选区域画面(不是整屏),底部工具栏包含箭头、文本、保存图片、复制图片;保存的 PNG 含标注且可正常打开;复制内容为图片。

## 8. 产物位置

- 录制文件: `<storageDirectory>/ScreenRecording_*.mp4`
- 截图文件: `<storageDirectory>/Screenshot_*.png`
- 设置文件: `%APPDATA%\dsh-screen-recorder\app-data\settings.json`(若该位置不可写,应用会自动回退到 `%TEMP%\dsh-screen-recorder`)
- 会话标记: `%APPDATA%\dsh-screen-recorder\app-data\recording-session.json`(仅录制期间存在)
- 构建产物: `dist/`
