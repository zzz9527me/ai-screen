# Feature Specification: 屏幕录制器 (Screen Recorder)

**Feature Branch**: `001-screen-recorder`

**Created**: 2026-10-18

**Status**: Draft

**Input**: User description: "做一款录屏软件:1) 可在 Windows 10 以上系统使用;2) 有三种录屏模式(全屏、选定区域、指定某个应用窗口);3) 录屏结束生成 MP4 格式的视频文件;4) 默认最小化在托盘上,右击弹出菜单含「录屏」「设置」;点击录屏弹出三个模式选择与开始按钮;5) 设置界面提供录屏设置,例如区域范围与录屏文件存储位置。"

## Clarifications

### Session 2026-10-18

- Q: 窗口录制过程中,如果目标应用窗口被调整大小,录制输出应如何处理? → A: 保持固定分辨率(录制开始时的窗口尺寸),画面缩放跟随窗口。
- Q: 区域范围的数值采用什么坐标单位,是否限制在主显示器内? → A: 使用 DIP(设备无关像素)为单位,且仅限主显示器范围内。
- Q: 输出视频采用什么帧率要求? → A: 固定 30 fps。
- Q: 停止录制并成功保存后,应用如何告知用户? → A: 系统通知 + 托盘提示。
- Q: 录制进行中,用户从托盘菜单选择退出应用时应如何处理? → A: 确认后停止并保存,再退出。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 托盘常驻并完成一次全屏录制 (Priority: P1)

用户启动录屏软件后,它收在系统托盘而不打扰工作。用户右击托盘图标,选择「录屏」,在弹窗中选择「全屏」并点击「开始」,录制自己的屏幕操作;录制结束后从托盘菜单停止录制,在配置的存储位置得到一个可播放的 MP4 文件。

**Why this priority**: 这是产品的最小可用闭环(托盘入口 + 全屏录制 + 停止 + MP4 输出)。其余模式复用同一录制管线,先交付它即可得到可用产品。

**Independent Test**: 在 Windows 10 环境启动应用 → 托盘右键 → 录屏 → 全屏 → 开始 → 操作屏幕 10 秒 → 从托盘菜单停止 → 用系统播放器打开输出文件,视频内容与操作一致且可正常播放。

**Acceptance Scenarios**:

1. **Given** 应用已启动, **When** 用户右击托盘图标, **Then** 菜单中出现「录屏」与「设置」选项。
2. **Given** 用户点击「录屏」, **When** 选择「全屏」并点击「开始」, **Then** 应用进入录制状态并持续捕获屏幕内容。
3. **Given** 录制进行中, **When** 用户从托盘菜单点击「停止录制」, **Then** 输出目录中出现一个 `.mp4` 文件,系统通知告知保存位置,且该文件可在系统默认播放器中播放本次操作内容。
4. **Given** 应用启动后未进行任何操作, **When** 用户查看任务栏, **Then** 应用不占用任务栏与前台窗口(仅托盘可见)。

---

### User Story 2 - 选定区域录制 (Priority: P2)

用户只需要录制屏幕中的一块区域(例如某个图表或对话框)。在模式选择中选「选定区域」,在屏幕上框选矩形区域并开始录制,停止后得到只包含该区域的 MP4。

**Why this priority**: 区域录制是常见诉求,依赖 US1 的录制管线;在 US1 完成后可独立交付。

**Independent Test**: 选择「选定区域」→ 在屏幕上框选约 640×480 的区域 → 录制 10 秒 → 停止;输出视频分辨率等于所选区域尺寸,画面内容正确。

**Acceptance Scenarios**:

1. **Given** 用户选择「选定区域」, **When** 用户框选矩形区域并点击开始, **Then** 录制只覆盖该矩形区域。
2. **Given** 用户在设置中配置了区域范围(位置与宽高), **When** 以「选定区域」开始录制且未重新框选, **Then** 使用设置中的区域范围进行录制。
3. **Given** 用户确认的矩形区域为空或超出屏幕边界, **When** 点击开始, **Then** 应用阻止开始并提示需要有效区域。

---

### User Story 3 - 设置界面与配置持久化 (Priority: P2)

用户希望录屏文件保存在指定目录,并需要精确控制区域范围。通过托盘菜单打开设置界面,修改存储位置与区域范围后关闭;下次启动应用或下次录制时配置仍然有效。

**Why this priority**: 配置能力决定录制产出的位置与区域精度,是用户明确要求的设置项;实现成本低,可与区域录制并行交付。

**Independent Test**: 打开设置 → 将存储位置改为新目录、区域范围改为指定值 → 关闭应用并重新启动 → 打开设置检查两处配置保持修改后的值;下次区域录制使用新区域范围并输出到新目录。

**Acceptance Scenarios**:

1. **Given** 打开设置界面, **When** 用户修改存储位置并保存, **Then** 之后录制的文件输出到新位置。
2. **Given** 用户修改区域范围, **When** 关闭并重新启动应用, **Then** 区域范围仍为修改后的值。
3. **Given** 存储位置不可写或已被删除, **When** 应用启动或开始录制, **Then** 应用使用默认位置或明确提示错误,不产生损坏文件。

---

### User Story 4 - 指定应用窗口录制 (Priority: P3)

用户想录制某个应用程序窗口(例如浏览器或演示软件)而不是整个屏幕。选择「指定应用窗口」,从可用窗口列表中选择目标窗口并开始录制;录制画面只包含该窗口,窗口移动时录制范围跟随窗口。

**Why this priority**: 窗口录制依赖窗口枚举与跟踪,技术难度最高;前三种能力可先交付,窗口模式作为后续增量。

**Independent Test**: 打开记事本 → 选择「指定应用窗口」→ 从列表选中记事本窗口 → 开始录制并在记事本中输入文字 → 停止;输出视频只包含记事本窗口,不含屏幕其他内容。

**Acceptance Scenarios**:

1. **Given** 用户选择「指定应用窗口」, **When** 查看可选窗口列表, **Then** 列表中包含当前可见的应用窗口。
2. **Given** 用户选中目标窗口并开始录制, **When** 移动窗口或调整窗口大小, **Then** 录制画面持续反映该窗口内容,输出分辨率保持开始录制时的窗口尺寸。
3. **Given** 录制中目标窗口被关闭, **When** 录制仍在进行, **Then** 录制自动结束、保存已录制内容并通过系统通知提示用户。

### Edge Cases

- 录制中目标窗口被最小化或被其他窗口遮挡:录制内容反映窗口的真实状态;窗口被调整大小时输出分辨率保持不变、画面缩放跟随;窗口被关闭时录制自动结束并保存已录制部分。
- 磁盘空间不足或存储目录无写权限:在损坏文件产生前停止录制并明确提示错误。
- 多显示器环境:全屏模式仅录制主显示器的内容,不提供选择其他显示器的选项。
- 用户连续快速点击「开始」:同一时间只允许一个录制会话,重复操作被忽略。
- 录制中应用被强制退出或系统异常:已录制内容应尽力完成封装(章程要求),无法修复时明确报告损坏,不得静默丢失。
- 录制中从托盘选择退出:弹出确认;确认后停止录制、保存并退出;取消则继续录制。
- 区域范围数值非法(宽或高 < 16 DIP、超出主显示器边界,单位为 DIP):保存设置时校验并拒绝非法配置。
- 录制时长较长(≥ 1 小时)的文件:输出文件仍应可完整播放。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 应用 MUST 在 Windows 10 及更高版本上运行。
- **FR-002**: 应用启动后 MUST 默认最小化到系统托盘,不显示前台窗口、不占用任务栏。
- **FR-003**: 托盘图标右键 MUST 弹出菜单,至少包含「录屏」与「设置」两个选项。
- **FR-004**: 点击「录屏」 MUST 弹出模式选择界面,提供「全屏」「选定区域」「指定应用窗口」三种模式与「开始」按钮;用户选择模式后可开始录制。
- **FR-005**: 全屏模式 MUST 录制主显示器的全部内容;多显示器环境下仅录制主显示器,不提供选择其他显示器的选项。
- **FR-006**: 选定区域模式 MUST 允许用户在屏幕上拖拽框选矩形区域作为录制范围,并支持取消框选。
- **FR-007**: 区域范围 MUST 以 DIP(设备无关像素)为单位、限定在主显示器边界内,宽高 MUST ≥ 16×16 DIP,并可在设置界面以数值(位置与宽高)配置,在区域录制时生效。
- **FR-008**: 指定应用窗口模式 MUST 提供当前可用应用窗口列表供用户选择;录制范围 MUST 与所选窗口的边界一致;录制过程中窗口尺寸变化时,输出分辨率 MUST 保持开始录制时的尺寸不变,画面按比例缩放适配。
- **FR-009**: 用户 MUST 能够停止正在进行的录制;录制进行中托盘菜单 MUST 显示「停止录制」选项,点击后停止录制;停止后 MUST 在已配置的存储位置生成一个 `.mp4` 文件。
- **FR-010**: 输出文件 MUST 使用 MP4 格式封装,并可由 Windows 系统默认媒体播放器直接播放。
- **FR-011**: 输出文件名 MUST 唯一(例如包含时间戳),不得覆盖已有文件。
- **FR-012**: 任何录制失败或异常中断 MUST 通过系统通知(系统通知不可用时托盘提示)向用户明确提示,不得静默丢弃已录制内容。
- **FR-013**: 应用同一时间 MUST 只允许一个录制会话。
- **FR-014**: 首版录制内容 MUST 仅包含画面,不录制音频(系统声音与麦克风均不收录),输出 MP4 文件不含音轨。
- **FR-015**: 设置界面 MUST 提供录屏文件存储位置配置,并支持浏览选择文件夹。
- **FR-016**: 设置修改 MUST 持久化保存,并在下次启动与下次录制时生效。
- **FR-017**: 存储位置 MUST 提供合理默认值:系统「视频」目录下的 `DSH Screen Recorder` 子文件夹,且允许用户更改。
- **FR-018**: 录制期间应用 MUST 保持托盘菜单可用,菜单交互不得阻塞录制。
- **FR-019**: 输出视频帧率 MUST 固定为 30 fps。
- **FR-020**: 停止并成功保存后,应用 MUST 通过 Windows 系统通知告知用户文件已保存及所在位置;系统通知不可用或被用户关闭时,MUST 在托盘提示(图标/提示文字)中体现保存结果。
- **FR-021**: 录制进行中用户退出应用 MUST 先请求确认;确认后 MUST 停止录制、保存并完成封装后再退出;取消确认 MUST 继续录制。
- **FR-022**: 所有用户界面(托盘菜单、模式选择窗口、设置窗口、区域框选覆盖层)MUST 采用统一、现代、美观的视觉设计:颜色、字体、间距、圆角与控件样式一致,元素对齐与留白合理,不得出现系统默认样式与自定义样式混杂的割裂感;同一界面中相同层级控件 MUST 复用同一组设计令牌(颜色、字体、间距、圆角),以 quickstart 场景 H 的检查项作为验收判据。
- **FR-023**: 所有可交互控件(按钮、单选、输入框、列表项)MUST 具备清晰的默认、悬停、按下、禁用与聚焦状态反馈;「开始」「停止」「保存」等主要操作 MUST 视觉突出且文案明确。
- **FR-024**: 界面 MUST 在 Windows 常见缩放比例(100%/125%/150%/200%)下保持清晰、布局不错位;窗口或面板尺寸变化时布局 MUST 自适应。

### Key Entities *(include if feature involves data)*

- **录制会话 (Recording Session)**: 一次从开始到结束的录制行为。关键属性:模式(全屏/区域/窗口)、捕获目标(屏幕、矩形区域或窗口)、开始时间、结束时间、状态(进行中/已完成/失败)、输出文件路径。
- **录制设置 (Recording Settings)**: 用户级配置。关键属性:区域范围(位置与宽高,单位 DIP)、存储位置、音频开关(首版固定为不录制)、恢复自默认值的行为。
- **捕获模式 (Capture Mode)**: 全屏、选定区域、指定应用窗口三种取值,决定捕获目标的定义方式。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 用户从右击托盘图标到开始录制不超过 10 秒。
- **SC-002**: 100% 成功完成的录制会话都生成可被系统默认播放器打开的 MP4 文件。
- **SC-003**: 在 Windows 10 与 Windows 11 上,三种录制模式各至少完成一次端到端录制并通过播放验证。
- **SC-004**: 区域录制输出视频的分辨率与所选区域尺寸一致。
- **SC-005**: 设置修改经重启应用后 100% 保持生效。
- **SC-006**: 5 名首次使用的用户中至少 4 名能在无指导下完成一次托盘发起的录制。
- **SC-007**: 对 10 分钟以内的录制,停止录制后 5 秒内文件可开始播放。
- **SC-008**: 录制期间目标应用的操作仍可正常进行,用户主观评分 ≥ 4/5。
- **SC-009**: 5 名首次使用的用户中至少 4 名对界面外观与易用性给出 ≥ 4/5 分(1–5 分)。

## Assumptions

- 单实例桌面应用,同一时间仅一个录制会话(章程要求)。
- 不提供全局快捷键;所有操作经托盘菜单与设置界面完成。
- 首版不包含音频录制,输出 MP4 为无音轨的纯画面视频。
- 帧率固定为 30 fps(FR-019);画质、码率与编码实现细节由实现自行决定,不在本规范约束。
- 录制画面需能清晰辨认屏幕操作内容即可,不追求高画质。
- 用户对所选存储目录拥有写权限。
- 应用为离线桌面应用,不需要网络连接。
- 首版不包含暂停/恢复录制、水印、视频剪辑、云上传等功能。
