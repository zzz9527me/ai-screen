## 2. 官方功能点摘录

### 2.1 截图

- 按 `F1` 开始截图。
- 自动检测界面元素区域。
- 像素级的鼠标移动控制与截图范围控制。
- 取色器(`F1`、`C`、`F3`)。
- 历史记录回放(`,` / `.`)。
- 支持多屏与高分辨率屏幕。
- 截图后可标注,再按 `F3` 将截图贴到屏幕。

### 2.2 标注

官方主页列出的画图工具:

- 矩形
- 椭圆
- 线条
- 箭头
- 铅笔(画笔)
- 马克笔(高亮)
- 文字

高级标注工具:

- 马赛克
- 高斯模糊
- 橡皮擦
- 撤销、重做

第三方评测补充:

- 选区后标注工具全部可就地使用。
- 线段类工具可调粗细、颜色;区域类工具支持边框/色块。
- 有全功能调色板,可调透明度。
- 所有标注可二次变形(首版暂不实现)。

### 2.3 贴图(Snipaste 的标志能力)

- 截图后按 `F3` 把截图置顶贴在屏幕上。
- 可将剪贴板里的图像、纯文本、HTML、颜色信息、图片文件转为贴图。
- 贴图窗口支持缩放、旋转、翻转、透明度、鼠标穿透、缩略图、标注、隐藏。
- 支持贴图分组、自动备份恢复、GIF。

### 2.4 交互细节(第三方评测)

- 打开截图后屏幕冻结/变暗,自动检测窗口与界面元素。
- 拖动选框边缘时出现放大镜,可像素级精确调整。
- 点击选框外的点可快速调整选框。
- 键盘方向键可像素级移动选框。
- 标注类型丰富,支持画笔、记号笔、文本、马赛克、模糊等 9 种工具。
- 截图与贴图是同一工具链:截图 → 标注 → 贴图。

## 3. 功能映射与本版范围

| Snipaste 能力 | 本版决策 | 说明 |
| --- | --- | --- |
| 冻结屏幕后框选 | ✅ 首版实现 | 先截全屏,再全屏覆盖并框选 |
| 选区移动/8 向缩放/尺寸显示 | ✅ 首版实现 | 最小 16×16 DIP,限制主屏 |
| 像素级控制(方向键/点击外部调整) | ⚠️ 部分实现 | 首版支持控制点与像素级拖动;方向键微调后续 |
| 放大镜/坐标/颜色 | ✅ 首版实现 | 显示放大像素、DIP 坐标、HEX 颜色 |
| 自动窗口/元素检测 | ❌ 后续 | 需要系统级 UI Automation/窗口边界,首版不做 |
| 矩形/椭圆/直线/箭头 | ✅ 首版实现 | 拖拽绘制 |
| 画笔/马克笔 | ✅ 首版实现 | 连续路径;马克笔半透明 |
| 文字 | ✅ 首版实现 | 点击输入,Enter/失焦提交 |
| 马赛克 | ✅ 首版实现 | 矩形区域像素化 |
| 高斯模糊 | ❌ 后续 | 首版用马赛克替代 |
| 橡皮擦 | ❌ 后续 | 首版用撤销/重做 |
| 颜色/线宽调整 | ✅ 基础实现 | 6 色;线宽按工具固定 |
| 撤销/重做 | ✅ 首版实现 | 覆盖所有标注 |
| 保存 PNG / 复制图片 | ✅ 首版实现 | 沿用现有存储目录与 IPC |
| 贴图(F3) | ✅ 基础实现 | 置顶、可拖动、可关闭 |
| 贴图缩放/旋转/翻转/透明度/穿透 | ❌ 后续 | 基础贴图先落地 |
| 历史回放(`,`/`.`) | ❌ 后续 | 撤销/重做已覆盖基本需求 |
| 多屏/跨屏 | ❌ 后续 | 与录屏一致,仅主屏 |
| OCR | ❌ 后续 | 非首版目标 |
| 标注二次编辑/变形 | ❌ 后续 | 首版通过撤销重做调整 |

## 4. 结论

首版采用 **Snipaste 的核心闭环**:

1. 触发即冻结主屏;
2. 全屏变暗后精确框选,带放大镜与像素信息;
3. 选区内就地标注(8 类工具 + 撤销/重做 + 6 色);
4. 保存 / 复制 / 基础贴图;
5. 全部键盘快捷操作。

自动窗口检测、OCR、历史回放、复杂贴图变换作为后续增强,不阻塞首版交付。
