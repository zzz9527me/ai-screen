# Feature Specification: Snipaste 风格截屏重构

**Feature Branch**: `002-snipaste-screenshot`

**Created**: 2026-10-19

**Status**: Implemented (v1)

**Input**: User description: "截图的功能参考 Snipaste 软件的实现;先联网整理 Snipaste 功能点写进 spec,再进行实现;不需要确认,先做一版并验证。"

## 背景

现有截屏是“托盘触发 → 透明选区层 → 裁剪 → 独立编辑窗口”的两段式流程,标注栏与截图画面分离,缺少 Snipaste 的冻结画面、精确选区、放大镜/取色、就地标注和贴图体验。本次按 Snipaste 的核心交互重构截屏。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 冻结屏幕并框选区域截图 (Priority: P1)

用户按下截屏快捷键后,当前屏幕画面立即冻结并变暗;用户拖动框选目标区域,松开后选区保持高亮,屏幕底部/选区旁出现标注工具栏。用户可以直接保存为 PNG 或复制到剪贴板。

**Why this priority**: 这是截屏的最小闭环,也是 Snipaste 最核心的“所见即所得”体验。

**Independent Test**: 触发截屏 → 拖动 600×400 区域 → 点保存 → 打开生成的 PNG,确认图片只包含所选区域且尺寸正确。

**Acceptance Scenarios**:

1. **Given** 应用在托盘运行, **When** 用户触发截屏, **Then** 主屏画面被冻结并整体变暗,光标变为十字,不出现独立编辑窗口。
2. **Given** 画面已冻结, **When** 用户按住鼠标拖出一个不小于 16×16 的区域并松开, **Then** 选区高亮显示、显示宽高、出现标注工具栏。
3. **Given** 已有选区, **When** 用户点击保存, **Then** 仅所选区域被保存为 PNG,文件写入设置的存储目录。

---

### User Story 2 - 就地标注与精确调整 (Priority: P2)

用户在选区内直接使用矩形、椭圆、直线、箭头、画笔、马克笔、文字、马赛克等工具标注;支持撤销/重做、切换颜色;通过放大镜查看像素颜色和坐标,用控制点移动/缩放选区。

**Why this priority**: Snipaste 的竞争力来自就地标注与像素级控制;没有这些,只是普通截图工具。

**Independent Test**: 框选区域 → 画箭头、矩形、文字、马赛克 → 撤销一步再重做 → 保存,确认所有标注出现在结果图中。

**Acceptance Scenarios**:

1. **Given** 已有选区, **When** 用户选择箭头并拖动, **Then** 选区内出现箭头,工具栏保持可用。
2. **Given** 已有选区, **When** 用户选择文字并点击选区, **Then** 出现可直接输入的文字框;按 Enter 或点击空白处后文字固定在图片上。
3. **Given** 已有标注, **When** 用户撤销, **Then** 最后一条标注消失;重做后恢复。
4. **Given** 鼠标在画面上移动, **When** 未开始绘制, **Then** 放大镜显示光标附近的放大像素、坐标与颜色值。
5. **Given** 已有选区, **When** 拖动控制点或选区内部, **Then** 选区可缩放/移动,最小 16×16,且不超出屏幕。

---

### User Story 3 - 贴图到屏幕 (Priority: P3)

用户完成选区后按 F3 或点击“贴图”,标注结果作为一个置顶图片窗口留在桌面上;窗口可拖动、可关闭。

**Why this priority**: “Snip + Paste”是 Snipaste 的标志性能力,首版提供基础贴图即可显著提升工具辨识度。

**Independent Test**: 截取并标注一个区域 → 点“贴图” → 桌面出现置顶图片;拖动窗口、关闭窗口均正常。

**Acceptance Scenarios**:

1. **Given** 已有选区, **When** 用户点击“贴图”或按 F3, **Then** 截图以无边框置顶窗口显示在屏幕上,原截屏层关闭。
2. **Given** 贴图窗口存在, **When** 用户拖动窗口, **Then** 窗口跟随移动;点击关闭按钮/双击,窗口关闭。

---

### Edge Cases

- 用户按 Esc:取消截屏,关闭冻结层,不生成文件,不报错。
- 选区小于 16×16:不确认选区,提示继续框选。
- 选区拖到屏幕外:自动裁剪到主屏边界内。
- 高 DPI(150%/200%):保存的图片尺寸与选区 DIP 比例正确,文字/箭头不模糊。
- 保存目录不可写:显示明确错误,不丢失当前截图。
- 剪贴板写入失败:保留选区与标注,显示错误,允许重试保存。
- 贴图窗口创建失败:提示错误,原截图不丢失。
- 截屏过程中再次触发快捷键:不重复创建冻结层。
- 录屏进行中触发截屏:不破坏录制会话;截屏层关闭后可继续录制。
- 只有一块主显示器时正常;多显示器首版仅覆盖主显示器。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 托盘「截屏」与用户配置的全局快捷键 MUST 触发同一套截屏流程。
- **FR-002**: 触发后 MUST 先冻结主显示器画面再进入选区,不得显示实时桌面或独立的图片编辑窗口。
- **FR-003**: 冻结画面 MUST 整体变暗,选区 MUST 保持原亮度;无选区时鼠标 MUST 为十字。
- **FR-004**: 用户 MUST 能拖拽创建选区、拖动选区移动、拖动 8 个控制点缩放;选区最小 16×16 DIP,且 MUST 限制在主屏内。
- **FR-005**: 选区旁 MUST 实时显示宽×高(DIP),并根据选区位置把工具栏放在选区下方或上方,保证不超出屏幕。
- **FR-006**: 鼠标移动时 MUST 提供放大镜,显示放大像素、屏幕坐标与颜色值;该信息不得遮挡主要选区。
- **FR-007**: 工具栏 MUST 提供:移动/选择、矩形、椭圆、直线、箭头、画笔、马克笔、文字、马赛克、撤销、重做、颜色选择、保存图片、复制图片、贴图、取消。
- **FR-008**: 矩形/椭圆/直线/箭头 MUST 支持拖拽绘制;画笔/马克笔 MUST 支持连续绘制;文字 MUST 支持直接输入并按 Enter 或失焦提交;马赛克 MUST 对选区内的图像区域进行像素化。
- **FR-009**: 所有标注 MUST 只渲染在选区内,不得出现在选区外或最终 PNG 之外。
- **FR-010**: 撤销/重做 MUST 覆盖所有标注操作;新标注后 MUST 清空重做栈。
- **FR-011**: 用户 MUST 能选择至少 6 种标注颜色,当前颜色 MUST 应用到新标注。
- **FR-012**: 保存 MUST 输出 PNG,仅包含选区,文件名 `Screenshot_YYYYMMDD_HHmmss.png`,同名自动追加序号,写入设置的存储目录。
- **FR-013**: 复制 MUST 将选区+标注合成后的图片写入 Windows 剪贴板。
- **FR-014**: 贴图 MUST 把选区+标注合成图显示为无边框置顶窗口,支持拖动和关闭。
- **FR-015**: 键盘 MUST 支持:Esc 取消、Ctrl+C 复制、Ctrl+S 保存、Ctrl+Z 撤销、Ctrl+Y 或 Ctrl+Shift+Z 重做、F3 贴图。
- **FR-016**: 截屏失败/保存失败/剪贴板失败 MUST 给出用户可见的错误信息,不得只写控制台。
- **FR-017**: 截屏功能 MUST NOT 改变录屏、区域录制、窗口录制的行为与设置兼容性。
- **FR-018**: 旧版设置文件 MUST 自动补全截屏快捷键字段,不得重置其他设置。

### Key Entities

- **Screenshot Session**:一次截屏行为,包含冻结图像、主屏尺寸、选区、标注列表、撤销/重做栈、创建时间。
- **Selection**:截图区域,包含 x/y/width/height(DIP)与对应的物理像素区域。
- **Annotation**:标注对象,类型为矩形/椭圆/直线/箭头/画笔/马克笔/文字/马赛克,包含几何、颜色、线宽等属性。
- **Pin Window**:置顶贴图窗口,包含合成图片、窗口位置与尺寸。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 用户从触发截屏到看到冻结画面不超过 1.5 秒。
- **SC-002**: 框选 600×400 DIP 区域后保存的 PNG,宽高比例与选区一致(缩放因子 2 时输出 1200×800 像素)。
- **SC-003**: 首次使用者在不看说明的情况下,能在 60 秒内完成“框选 → 画箭头 → 输入文字 → 保存”。
- **SC-004**: 8 种标注工具均能在保存结果中产生可见效果;撤销/重做 100% 恢复标注状态。
- **SC-005**: 复制到剪贴板的图片类型为 `image/png`,尺寸与选区一致。
- **SC-006**: 完整截屏流程在开发版与打包版中控制台错误、页面错误均为 0。
- **SC-007**: 录屏三种模式的自动化回归全部通过,不出现新的 0 字节或启动失败。

## Assumptions

- 首版仅覆盖主显示器;多显示器同时框选属于后续版本。
- 首版不实现 Snipaste 的自动窗口/元素检测、历史记录回放(`,`/`.`)、OCR、标注二次编辑、GIF 贴图、贴图旋转/翻转/透明度/鼠标穿透;这些记录为后续增强。
- 截屏不改变系统剪贴板中的非图片内容,除非用户主动复制。
- 用户使用 Windows 10/11 x64,显示缩放可为 100%–200%。
- 存储目录沿用录屏设置,截图与录像保存在同一目录。

## Out of Scope (first version)

- 自动检测窗口/界面元素边界。
- 多显示器选区与跨屏截图。
- 截图历史回放。
- OCR/文字识别。
- 已绘制标注的二次变形/属性编辑。
- 贴图的分组、旋转、翻转、透明度、鼠标穿透、GIF 播放。
- 滚动截图。
